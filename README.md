# RaceDay - Event Management System


## Overview

RaceDay is a full-stack web-based event management system designed for the South African road running, walking, and cycling community. The platform enables Event Organisers to create and manage events, categories, and participant results, while Participants can browse upcoming events, enter events, track their personal performance history, and prepare for race day using live weather and route information.

## Features

- **Event Management**: Create, update, and delete events with detailed information
- **Category Management**: Define event categories with age groups, distances, and difficulty levels
- **Participant Enrolment**: Register for events and track enrolment status
- **Results Tracking**: Upload and view event results with rankings
- **User Profiles**: Manage personal information and view performance history
- **Weather & Route Info**: Real-time weather updates and route descriptions for race day preparation

## Technology Stack

- **Backend**: Node.js, Express.js
- **Database**: Microsoft SQL Server
- **Authentication**: JWT
- **CI/CD**: GitHub Actions
- **Containerization**: Docker
